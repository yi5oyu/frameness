# AGENTS.md

## 작업 절차

계획(ep) = `docs/plans/active/ep-{YYYYMMDD}-{slug}.md` — `ep-0000-template.md`를
복사해 만든다. **계획 파일만이 상태다.** `docs/plans/` 안은 승인 없이 쓴다.

1. **계획** — 관련 코드를 먼저 읽고 범위를 파악한 뒤 템플릿을 채운다.
   `## Acceptance Criteria`는 판정 가능하게. 모호하면 한 번에 묻는다.
2. **승인** — 계획 경로·파일·기준을 제시하고 대기한다. **대기 중 도구 호출 금지.**
   승인되면 파일·기준 사본을 `## Approval`에 남기고 Status를 `[Approved]`로 바꾼다.
3. **구현** — 승인된 파일만, 기준에 필요한 만큼만 고친다. 첫 소스 변경 직전에
   Status를 `[In Progress]`로 바꾸고, 변경 즉시 `## Change Log` 1줄.
4. **검증** — `## Approval`의 기준을 하나씩 확인해 `## Acceptance Criteria`에
   체크하고, 통과·실패와 커밋 메시지 안을 함께 제시한다. 인간 승인.
5. **마감** — Status를 `[Done]`으로 바꾸고 `done/`으로 옮긴 뒤 커밋
   (제목 한 줄 + 푸터 `ep: {slug}`).

- 계획(ep)에서 `## Approval`·`## Change Log`·`## Run History`는 append 전용이다
  — 지난 줄을 고쳐 현실에 맞추지 않는다. 나머지 섹션은 제자리에 채운다.
  Status와 기준 체크박스는 갱신하되, Status는 그 상태를 만든 변경보다 먼저
  기록한다. `## Affected Files`에 파일을 더하는 것은 재승인 대상이다.
- 트레이드 오프 판단 과정에서 선택한 것과 버린 대안·그 이유를 `## Decisions`에 남긴다 — 코드에서 복원되지 않는 것은 버린 쪽이다.
- 애매하면 승인이 아니다 — 재제시한다. 중단으로 읽히면 중단한다.
- 실행이 끝날 때마다 `## Run History` 1줄 — 완료·중단·실패 모두.
- 하위 폴더의 AGENTS.md는 그 폴더의 사실(`## 명령어`·`## 구조`·`## 금지`)을 담는다
  — 계획 단계에서 읽고, 검증은 걸친 폴더 전부의 `## 명령어`를 실행한다.
