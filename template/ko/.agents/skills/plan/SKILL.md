# plan — 인터뷰로 계획 벼리기

작업할 폴더에 AGENTS.md가 없거나 `## 명령어`가 비어 있으면 `setup`을 먼저
요청하라고 안내하고 멈춘다 — 스택이 정해지기 전의 계획은 검증할 수 없다.

1. **먼저 조사한다.** 사실(코드베이스·스택·기존 패턴)은 직접 찾아보고 묻지
   않는다. Affected Files 후보가 걸친 폴더의 AGENTS.md를 읽는다 — 그 `## 금지`가
   계획을 바꾼다.
2. **한 번에 하나씩 묻는다.** 묶어 물으면 답이 흐려진다. 질문마다 권고안을
   붙인다. 사용자 몫은 **결정**(목표·범위·트레이드오프)뿐이다.
3. 답이 계획을 바꾸면 바뀐 이해를 한 줄로 다시 말하고 확인받는다.
4. 결정할 것이 남지 않으면 `ep-0000-template.md` 사본을 합의 내용으로 채워
   `[Draft]`로 저장한다. 기준은 하나하나 판정 가능한 문장이어야 한다.
   프로젝트 전체에 지속되는 결정(스택·컨벤션·명령어)은 ep가 아니라 그 폴더의
   AGENTS.md로 간다.
5. ep 경로를 알리고 **`execute`를 요청하라고 안내한 뒤 멈춘다.**
   여기서 승인을 요청하지 않는다 — 승인은 execute가 받아 `## Approval`에
   기록한다. 승인의 주체를 하나로 두기 위해서다.
6. ep `## Run History` 1줄.

**끝났다고 볼 때:** `docs/plans/active/`에 ep [Draft]가 있고 · 기준이 전부
판정 가능하고 · Run History 1줄이 있다.
