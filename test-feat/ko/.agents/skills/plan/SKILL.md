# plan — 인터뷰로 계획 벼리기

모호한 요구를 받았을 때, 합의된 ep [Draft]가 생길 때까지 인터뷰한다.

1. **조사 먼저.** 코드베이스·스택·기존 패턴 같은 **사실**은 질문하지 않고
   직접 찾는다.
2. **한 번에 하나씩 질문한다.** 여러 질문을 묶으면 답이 흐려진다.
   각 질문에 추천안을 붙인다. **결정**(목표·범위·트레이드오프)만 사용자 몫이다.
3. 답이 계획을 바꾸면, 바뀐 이해를 한 줄로 되말해 확인받는다.
4. 더 물을 결정이 없으면: 합의 내용을 `ep-0000-template.md` 복사본에 채워
   `[Draft]`로 저장한다. 모든 인수 기준이 검증 가능한 문장인지 확인한다.
   결정 중 프로젝트 전체에 지속되는 것(스택·컨벤션·테스트 명령)은 ep가 아니라
   AGENTS.md `## Project Overview` 또는 해당 폴더의 중첩 AGENTS.md에 기록한다.
5. 승인 게이트(AGENTS.md 계약)를 표시하고 종료한다 — 합의 전·승인 전에는
   어떤 소스 수정도 하지 않는다.

**완료 기준:** `docs/plans/active/`에 ep [Draft] 존재 + 인수 기준 전부 체크 가능.
